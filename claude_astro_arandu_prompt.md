# Claude Prompt --- Arandu Portfolio (Astro)

You are a senior frontend engineer and designer.

Your task is to build a complete developer portfolio using Astro,
following a minimal, clean, and professional design system.

The portfolio is called **Arandu**.

------------------------------------------------------------------------

## Concept

Arandu means "knowledge" (Tupi-Guarani).\
The portfolio should feel like a **place of engineering knowledge and
systems thinking**, not a flashy personal website.

Tone: - calm - precise - intentional - minimal - technical

Avoid: - flashy animations - excessive colors - startup-style landing
pages

------------------------------------------------------------------------

## Tech Requirements

-   Use Astro
-   Use Tailwind CSS for styling
-   Keep everything simple and readable
-   Use static data (no backend required)
-   Components should be reusable and clean

------------------------------------------------------------------------

## Pages

Create:

1.  `/` (homepage)
2.  `/projects` (optional but preferred)

------------------------------------------------------------------------

## Layout Structure

### Homepage sections (in order)

1.  Hero
2.  Selected Work (projects)
3.  About
4.  Links

------------------------------------------------------------------------

## Hero Section

Content:

Arandu\
---\
Systems, APIs and developer tools

by Leonardo Cardoso

Optional subtitle: Backend & Cloud Engineer focused on building reliable
systems.

Design: - centered or slightly left-aligned - large typography - lots of
whitespace - subtle accent color

------------------------------------------------------------------------

## Projects Section

Title: "Selected Work"

Display 3--4 projects as cards.

Projects:

1.  IncidentLens\
    AI-powered incident analysis system\
    Highlights:

    -   async processing\
    -   LLM-based reasoning\
    -   event-driven architecture

2.  Hookbox\
    Webhook inspection tool

3.  Ticket Analyzer\
    AI-based ticket classification

4.  Apidiff\
    API diffing tool

Each card should: - be minimal - include name, short description, and
tags - have subtle hover effect (border or glow)

------------------------------------------------------------------------

## About Section

Short paragraph:

"I build backend systems and developer tools with a focus on
reliability, clarity and real-world use cases. Currently focused on
Python, AWS and distributed systems."

## Links Section

-   GitHub
-   LinkedIn

-   no heavy shadows
-   no gradients

-   clean folder structure
-   well-named components
-   no unnecessary complexity
-   production-ready code

------------------------------------------------------------------------

## Output

Generate:

1.  Astro project structure
2.  All necessary files
3.  Tailwind config
4.  Example data for projects
5.  Clean, readable code

------------------------------------------------------------------------

The result should feel like a **real portfolio used by a backend
